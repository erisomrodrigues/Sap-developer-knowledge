## TIPS & TRICKS
1. Usando [CASE dentro do SELECT](/TIPS_&_TRICK/CODE/ZPROG_SELECT_WITH_CASE_ERI.ABAP) para modificar campos na tabela interna
2. Formatação de texto para LOG [New Syntax WRITER](/TIPS_&_TRICK/CODE/ZPROG_NEW_SYNTAX_TEXT_LOG_ERI.ABAP) baixando arquivo TXT com module funcção GUI_DOWNLOAD .
3. Realizando um [LOOP AT reverso](/TIPS_&_TRICK/CODE/ZPROG_LOOP_REVERSE_STEP_ERI.ABAP) com a instrução STEP e o comando COLOR para mudar sobra de textos.
4. Formatação de textos com [TO_UPPER CASE, TO_LOWER CASE e TRANSLATE](/TIPS_&_TRICK/CODE/ZPROG_TRANSLATE_UPPER_LOWER.ABAP)
5. Expressões incorporadas em modelo de string [SY-DATUM, SY-UZEIT, CURRENCY, WIDTH e ALPHA](/TIPS_&_TRICK/CODE/ZPROG_STRING_EMBEDDED_ERI.ABAP)  ABAP moderno
6. Uso do comando [TO UPPER e do UPPER](/TIPS_&_TRICK/CODE/ZPROG_SELECT_UPPER_ERI.ABAP) para tornas tonar conteúdo em caixa alta, e o uso em SQL após a clausula WHERE.
7. Usando o [_CLEAR_](TIPS_&_TRICK/CODE/zprg_structure_with_clear_eri.abap) com _WITH_ para escolher quais campos **NÃO** limpar de uma estrutura.
8. Usando o [ASSIGN](TIPS_&_TRICK/CODE/ZPRG_ASSIGN_PILHA_ABAP.ABAP) para recuperar valores pela pilha ABAP que não existem localmente ou globalmente.
9. usando o comando [STEP](TIPS_&_TRICK/CODE/ZLOOP_BACKWARD_DIRECTION_ERI.ABAP) -1 para realizar um _`LOOP`_ inverso.
